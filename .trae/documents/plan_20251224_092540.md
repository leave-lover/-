# 能源防御与攻击平台系统流程图

## 流程概述

根据项目分析，能源防御与攻击平台的主要流程包括系统启动、拓扑可视化、攻击模拟、防御模拟、系统状态监控和数据分析等核心功能模块。流程图将展示用户如何使用这些功能模块以及它们之间的关系。

## 流程图结构

1. **系统启动**：运行后端服务和前端应用
2. **进入系统主页面**：显示能源网络拓扑图
3. **数据导入**：上传能源系统数据
4. **核心功能分支**：
   - 攻击模拟
   - 防御模拟
   - 系统优化
5. **结果查看**：
   - 攻击模拟结果
   - 防御模拟结果
   - 系统状态监控
   - 数据可视化图表
6. **系统退出**

## 详细说明

1. **系统启动**：用户可以通过运行start-all.bat脚本或手动启动后端和前端服务来启动系统。
2. **主页面**：系统启动后，用户进入主页面，主页面显示能源网络拓扑图。
3. **数据导入**：用户可以上传能源系统数据，包括电力系统和天然气系统的数据。
4. **功能模块**：
   - **攻击模拟**：用户可以配置攻击参数，模拟不同的攻击场景。
   - **防御模拟**：用户可以配置防御策略，模拟防御效果。
   - **系统优化**：系统可以进行优化计算，提高能源系统的效率和可靠性。
5. **结果查看**：
   - **攻击结果**：显示攻击模拟的结果，包括攻击路径、系统损伤等。
   - **防御结果**：显示防御模拟的结果，包括防御效果、系统恢复情况等。
   - **系统状态监控**：实时监控能源系统的运行状态，包括发电机输出、流量分布、节点状态等。
   - **数据可视化分析**：通过图表等形式展示系统数据，帮助用户分析系统运行情况。
6. **系统退出**：用户可以退出系统，结束使用。

这个流程图将清晰地展示能源防御与攻击平台的主要功能模块和用户操作流程，帮助用户理解系统的使用方法和功能关系。
