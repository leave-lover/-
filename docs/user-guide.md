# 能源防御与攻击平台用户指南

## 1. 平台概述

能源防御与攻击平台是一个用于能源系统拓扑可视化、攻击模拟和优化的综合平台。本指南将帮助您快速上手使用该平台，了解其核心功能和操作方法。

## 2. 快速开始

### 2.1 安装要求

- **前端**: Node.js 18+, npm 9+
- **后端**: Python 3.8+, pip

### 2.2 启动平台

#### 2.2.1 使用启动脚本（推荐）

Windows 系统:

```bash
start-all.bat
```

PowerShell:

```bash
start-all.ps1
```

#### 2.2.2 手动启动

1. **启动后端服务**:

   ```bash
   cd backend
   python app.py
   ```

2. **启动前端开发服务器**:

   ```bash
   cd frontend
   npm install  # 首次运行需要安装依赖
   npm run dev
   ```

3. **访问平台**:

   打开浏览器，访问 `http://localhost:5173`

## 3. 平台界面

### 3.1 整体布局

平台界面主要分为以下几个部分：

- **顶部导航栏**: 显示平台名称和版本信息
- **左侧边栏**: 功能模块导航和系统状态
- **中央区域**: 主要功能展示区，包括拓扑图和分析结果
- **右侧边栏**: 详细信息和参数设置
- **底部状态栏**: 显示系统状态和操作提示

### 3.2 左侧边栏功能

- **拓扑可视化**: 查看和操作能源系统拓扑图
- **攻击模拟**: 进行攻击场景模拟和分析
- **防御模拟**: 进行防御策略模拟和分析
- **系统分析**: 进行系统数据分析和优化
- **系统状态**: 查看系统运行状态和资源使用情况

## 4. 核心功能使用

### 4.1 拓扑可视化

#### 4.1.1 加载拓扑数据

1. 点击左侧边栏的"拓扑可视化"按钮
2. 在右侧边栏选择数据文件或使用默认数据
3. 点击"加载数据"按钮

#### 4.1.2 拓扑图操作

- **缩放**: 使用鼠标滚轮或触摸板缩放拓扑图
- **平移**: 按住鼠标左键拖动拓扑图
- **旋转**: 按住鼠标右键拖动拓扑图
- **节点选择**: 点击节点查看详细信息
- **边选择**: 点击边查看详细信息

#### 4.1.3 拓扑图设置

- **显示模式**: 切换电力系统、天然气系统或耦合系统视图
- **节点颜色**: 根据不同属性（类型、状态等）设置节点颜色
- **边宽度**: 根据不同属性（流量、容量等）设置边宽度
- **布局算法**: 选择不同的图布局算法

### 4.2 攻击模拟

#### 4.2.1 配置攻击参数

1. 点击左侧边栏的"攻击模拟"按钮
2. 在右侧边栏选择攻击类型：
   - 节点攻击
   - 边攻击
   - 组合攻击
3. 设置攻击参数：
   - 攻击目标（节点或边）
   - 攻击强度
   - 攻击时间
   - 攻击算法

#### 4.2.2 执行攻击模拟

1. 点击"开始攻击"按钮
2. 观察攻击过程和实时效果
3. 查看攻击结果和影响分析

#### 4.2.3 攻击结果分析

- **攻击路径**: 查看攻击传播路径
- **影响范围**: 查看受影响的节点和边
- **性能指标**: 查看系统性能变化
- **攻击效果**: 查看攻击成功率和影响程度

### 4.3 防御模拟

#### 4.3.1 配置防御参数

1. 点击左侧边栏的"防御模拟"按钮
2. 在右侧边栏选择防御类型：
   - 节点加固
   - 边保护
   - 系统重构
3. 设置防御参数：
   - 防御目标（节点或边）
   - 防御强度
   - 防御资源
   - 防御算法

#### 4.3.2 执行防御模拟

1. 点击"开始防御"按钮
2. 观察防御过程和实时效果
3. 查看防御结果和效果分析

#### 4.3.3 防御结果分析

- **防御效果**: 查看防御成功率和效果
- **资源使用**: 查看防御资源消耗
- **系统恢复**: 查看系统恢复情况
- **成本效益**: 分析防御成本和效益

### 4.4 系统分析

#### 4.4.1 统计分析

1. 点击左侧边栏的"系统分析"按钮
2. 选择"统计分析"选项
3. 查看系统各项统计指标：
   - 节点数量和类型分布
   - 边数量和类型分布
   - 系统容量和负载
   - 系统可靠性指标

#### 4.4.2 脆弱性分析

1. 在系统分析模块中选择"脆弱性分析"
2. 选择分析算法和参数
3. 点击"开始分析"按钮
4. 查看脆弱性分析结果：
   - 关键节点识别
   - 关键边识别
   - 系统脆弱性评分
   - 改进建议

#### 4.4.3 参数敏感性分析

1. 在系统分析模块中选择"参数敏感性分析"
2. 选择要分析的参数
3. 设置参数变化范围
4. 点击"开始分析"按钮
5. 查看参数敏感性分析结果：
   - 参数对系统性能的影响
   - 敏感参数识别
   - 优化建议

#### 4.4.4 系统优化

1. 在系统分析模块中选择"系统优化"
2. 选择优化目标：
   - 成本优化
   - 可靠性优化
   - 效率优化
3. 设置优化约束和参数
4. 点击"开始优化"按钮
5. 查看优化结果：
   - 优化前后对比
   - 优化建议
   - 优化算法性能

## 5. 数据管理

### 5.1 数据导入

1. 在左侧边栏选择"数据管理"或相关功能模块
2. 点击"导入数据"按钮
3. 选择数据文件（支持TXT、JSON、Excel等格式）
4. 设置数据导入参数
5. 点击"确认导入"按钮

### 5.2 数据导出

1. 在相关功能模块中查看分析结果
2. 点击"导出数据"按钮
3. 选择导出格式（支持JSON、CSV、Excel等格式）
4. 设置导出参数
5. 点击"确认导出"按钮

### 5.3 数据格式

平台支持以下数据格式：

- **拓扑数据**: JSON格式，包含节点和边信息
- **运行数据**: TXT或Excel格式，包含系统运行参数
- **分析结果**: JSON、CSV或Excel格式

## 8. 常见问题

### 8.1 平台无法启动

- 检查Node.js和Python版本是否符合要求
- 检查依赖是否正确安装
- 查看控制台输出的错误信息
- 确保端口5173和后端端口未被占用

### 8.2 拓扑图无法加载

- 检查数据文件格式是否正确
- 确保数据文件包含完整的节点和边信息
- 查看浏览器控制台的错误信息

### 8.3 攻击模拟运行缓慢

- 检查系统资源使用情况
- 减少攻击目标数量或降低模拟精度
- 优化算法参数

### 8.4 分析结果不准确

- 检查输入数据的准确性
- 调整分析算法参数
- 确保模型设置正确

## 9. 故障排除

### 9.1 前端错误

- 查看浏览器控制台的错误信息
- 检查网络连接是否正常
- 清除浏览器缓存
- 重新启动前端开发服务器

### 9.2 后端错误

- 查看后端控制台的错误信息
- 检查Python依赖是否正确安装
- 检查数据文件是否存在且格式正确
- 重新启动后端服务
