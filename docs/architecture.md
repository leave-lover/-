# 能源防御与攻击平台架构设计

## 1. 系统概述

能源防御与攻击平台是一个集前端可视化、后端计算和数据分析于一体的综合系统，用于研究和分析能源系统的脆弱性、攻击场景和优化策略。

## 2. 系统架构

### 2.1 整体架构

系统采用前后端分离的架构设计，主要包括以下几个层次：

```
┌─────────────────┐     ┌─────────────────┐     ┌─────────────────┐
│                 │     │                 │     │                 │
│   前端应用层     │     │   后端服务层     │     │   数据存储层     │
│  (React + TS)    │────▶│   (Flask)       │────▶│   (File System)  │
│                 │     │                 │     │                 │
└─────────────────┘     └─────────────────┘     └─────────────────┘
```

### 2.2 前端架构

前端采用模块化设计，主要包括以下几个模块：

#### 2.2.1 核心模块

- **拓扑可视化模块**: 负责能源系统拓扑图的展示和交互
- **攻击模拟模块**: 实现攻击场景的模拟和分析
- **防御模拟模块**: 实现防御策略的模拟和分析
- **数据分析模块**: 负责系统数据的分析和可视化
- **系统优化模块**: 实现系统优化算法

#### 2.2.2 共享组件

- **Sidebar**: 侧边栏组件，用于导航和功能切换
- **TabBar**: 标签栏组件，用于多标签页管理
- **ChartComponent**: 图表组件，用于数据可视化
- **Modal**: 模态框组件，用于交互和信息展示

### 2.3 后端架构

后端采用分层设计，主要包括以下几个层次：

#### 2.3.1 API层

- 提供RESTful API接口，用于前后端通信
- 处理HTTP请求和响应
- 实现身份验证和授权（可选）

#### 2.3.2 业务逻辑层

- 实现核心业务逻辑，包括：
  - 数据处理和分析
  - 攻击算法实现
  - 防御算法实现
  - 优化算法实现

#### 2.3.3 数据访问层

- 负责数据的读取和写入
- 支持多种数据格式（JSON、TXT、Excel等）
- 实现数据缓存和管理

## 3. 核心功能模块

### 3.1 拓扑可视化模块

#### 3.1.1 功能描述

- 交互式能源系统拓扑图展示
- 支持电力和天然气系统的耦合展示
- 节点和边的详细信息查询
- 拓扑图的缩放、平移和旋转
- 攻击路径的可视化

#### 3.1.2 技术实现

- 使用act-force-graph-2d库实现拓扑图绘制
- 采用React组件化设计
- 支持实时数据更新和交互

### 3.2 攻击模拟模块

#### 3.2.1 功能描述

- 多种攻击场景的模拟
- 实时显示攻击效果
- 攻击算法的实现与分析
- 攻击路径的可视化展示

#### 3.2.2 技术实现

- 采用Python实现攻击算法
- 支持多种攻击类型（节点攻击、边攻击等）
- 实时计算攻击影响并返回结果

### 3.3 防御模拟模块

#### 3.3.1 功能描述

- 多种防御策略的模拟
- 实时显示防御效果
- 防御算法的实现与分析

#### 3.3.2 技术实现

- 采用Python实现防御算法
- 支持多种防御类型（节点加固、边保护等）
- 实时计算防御效果并返回结果

### 3.4 数据分析模块

#### 3.4.1 功能描述

- 统计分析
- 报告生成
- 脆弱性分析
- 参数敏感性分析
- 优化算法的实现

#### 3.4.2 技术实现

- 使用Pandas和NumPy进行数据分析
- 使用Recharts进行数据可视化
- 支持多种分析方法和算法

## 4. 数据流程

### 4.1 数据导入流程

1. 用户上传数据文件
2. 后端解析数据文件
3. 转换为标准化格式
4. 存储到数据目录
5. 前端加载并可视化数据

### 4.2 攻击模拟数据流程

1. 用户选择攻击场景和参数
2. 前端发送请求到后端
3. 后端执行攻击算法
4. 计算攻击影响和结果
5. 返回结果到前端
6. 前端可视化展示攻击效果

### 4.3 防御模拟数据流程

1. 用户选择防御策略和参数
2. 前端发送请求到后端
3. 后端执行防御算法
4. 计算防御效果和结果
5. 返回结果到前端
6. 前端可视化展示防御效果

## 5. 技术栈

### 5.1 前端

- **框架**: React 18
- **语言**: TypeScript
- **构建工具**: Vite 5
- **可视化库**: act-force-graph-2d, recharts
- **状态管理**: React Context API

### 5.2 后端

- **语言**: Python 3.8+, JavaScript
- **Web 框架**: Flask
- **计算库**: NumPy, Pandas, SciPy
- **优化求解器**: Gurobi/PuLP

## 6. 部署架构

### 6.1 开发环境
